# Security Policy

## Scope

Mobile Hacked or Not Checker is an experimental, read-only Android inspection utility. It searches for selected indicators; it is not a forensic suite and cannot prove that a device is compromised or safe.

## Reporting a potential issue

Please do not publish private device logs, serial numbers, account names, IP addresses, or other personal information in a public issue. Share a minimal reproducible description and redact sensitive values. For a serious issue, contact the repository maintainer privately through GitHub before public disclosure.

## Safe use

- Scan only devices you own or have explicit permission to assess.
- Review the source before running it.
- Keep Android Platform Tools and your operating system updated.
- Do not use scanner output alone to accuse someone of surveillance or malware installation.
- This tool does not remove malware, modify device settings, or replace professional incident response.

## Limitations

ADB access and Android-version differences can limit visibility. Package names, permissions, network connections, logs, root indicators, and certificates can have legitimate explanations. False positives and false negatives are possible.
